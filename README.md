# Hamza Weslati — Interactive Portfolio

A bright, motion-first portfolio built with Vite, GSAP, ScrollTrigger and Lenis.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Main structure

- `index.html` — interactive single-page portfolio
- `projects.html` — full project archive
- `src/main.js` — smooth scroll, GSAP motion, project transitions, cursor and interactions
- `src/archive.js` — archive-page motion
- `src/style.css` — responsive visual system

The featured work is based on the public GitHub projects Noire, TITAN-GYM and APEXREDLINE.
